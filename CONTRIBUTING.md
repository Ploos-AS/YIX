# Contributing to µIX

Use English for normative text and shared technical discussions. Open an issue or pull request with scope, rationale, tests and compatibility impact. Normative changes follow the MIP process in mips/README.md.

Contribute only material you have rights to submit under the applicable project license: MIT for original code and CC BY 4.0 for original documentation, subject to LICENSING.md. Identify third-party material and preserve notices. No copyright assignment or contributor agreement is introduced by this policy.

Run relevant tests and disclose untested changes. Use synthetic addresses and sanitized fixtures; never submit production secrets or participant-sensitive data. Security reports follow SECURITY.md. Follow CODE_OF_CONDUCT.md.
