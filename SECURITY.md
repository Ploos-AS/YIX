# Security policy

µIX is currently a planning-stage infrastructure project with **no live exchange service and no supported software release**.

## Reporting issues

For security-sensitive findings, avoid public issues or pull requests. Contact Ploos AS using a verified private contact channel published by the organization. A dedicated µIX security address and response SLA will be documented before deployment.

Do not include credentials, private keys, customer data, private network diagrams or exploit details in public reports.

## Repository boundaries

This repository should contain sanitized examples, design documents and virtual-lab configuration only. Production secrets, device backups, access credentials and sensitive operating details belong in separately access-controlled systems.

The presence of this policy does not imply that a production security response team or SLA is already in place.
