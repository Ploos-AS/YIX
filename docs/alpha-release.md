# Alpha release checklist

Proposed tag: v0.1.0-alpha. Publish as a GitHub prerelease only after review of the merged candidate.

- [ ] Confirm all applicable CI checks pass on the candidate commit.
- [ ] Run toolkit unit tests and validate all three example inventories.
- [ ] Review lab results and disclose any untested components.
- [ ] Verify documentation links, website language navigation and license inventory.
- [ ] Record exact commit, test results and known limitations.
- [ ] Approve release notes, then create tag and prerelease.

The specification remains v0.1 working draft. No production or certification claim. Website publication and SIR1 activation are separate gates. No tag or release has been created by this preparation.
