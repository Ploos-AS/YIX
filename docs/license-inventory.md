# Licensing inventory and release gate

The intended split is MIT for original code/configuration and CC BY 4.0 for original documentation/specification. Full texts are included in the repository. Before declaring the entire repository licensed, review the complete tracked file inventory, contribution history, copied examples, dependencies, images, fonts and generated assets. Record provenance, rights holder, applicable license and required notices; retain third-party terms. Resolve unknown rights before release. This review is pending, not certified complete.

Use SPDX-License-Identifier: MIT for verified original code where appropriate and CC-BY-4.0 for verified original prose. Mixed files should identify code examples separately. Brand assets are excluded pending a separate policy.
