# Licensing inventory and release gate

The intended split is MIT for original code/configuration and CC BY 4.0 for original documentation/specification. Full texts are included in the repository. Before declaring the entire repository licensed, review the complete tracked file inventory, contribution history, copied examples, dependencies, images, fonts and generated assets. Record provenance, rights holder, applicable license and required notices; retain third-party terms. Resolve unknown rights before release. Maintainer review recorded 2026-11-27: tracked inventory, contributor summary, submodule status and dependency references inspected; project owner confirms rights to license original material and no known unauthorized third-party material. This is not an independent legal audit. Exact dependency package licenses and redistribution obligations require separate review before distributing images.
