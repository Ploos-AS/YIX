# µIX Open Framework v0.1.0-alpha

Small exchange. Big connections.

First planned public prerelease of an open framework for independent small Internet exchanges. Includes draft specification v0.1, Nano/Micro/Regional profiles, reference architecture, virtual BGP lab, offline inventory toolkit, conformance evidence templates, governance and bilingual website source.

Local results: five unit tests passed, three example inventories validated, README and website local links passed. Single-switch warnings expected for Nano and Micro.

## Limitations

Not a ratified standard, production deployment tool or certification. Synthetic BGP/RPKI lab does not establish physical or multi-vendor interoperability. Monitoring overlay, live feeds, physical redundancy and production security remain unverified. SIR1 in Sirdal, Norway is planned, not operational. Website deployment is separate.
