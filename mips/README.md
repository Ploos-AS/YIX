# µIX Improvement Proposals (MIPs)

Submit a proposal using TEMPLATE.md. Maintainers assign unique numbers after submission. States: Draft, Review, Accepted, Rejected, Withdrawn, Superseded. Acceptance is not implementation or release.

Normative proposals normally receive at least 14 days of public review. Record objections, resolution, decision rationale and affected requirements. Security-sensitive proposals follow SECURITY.md. Accepted changes identify target specification revision, migration and test updates. See GOVERNANCE.md.
